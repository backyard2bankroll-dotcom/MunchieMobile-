🍿 One-Time Setup

Your Snack Shack needs to be connected to Google Sheets. Follow these steps once and you'll never have to upload a file again.

Step 1
Go to script.google.com and click New Project
Step 2
Delete everything in the editor and paste in the code from the Code.gs file provided to you
Step 3
Click Deploy → New Deployment → Web App. Set "Who has access" to Anyone. Click Deploy and copy the URL it gives you.
Step 4
Paste that URL below and tap Connect
